# ADR 0001：阿里云适配与上游执行引擎分离

状态：接受。日期：2026-10-13。

## 背景

Easel v0.3.0 引入多执行引擎，并将内置技能迁移到 `skills/builtin/`、共享工作区迁移到 `agents/workspace/`。
本 Fork 已有经过实测的阿里云聊天、生图、视频、配音、转写和音乐配置，需要持续吸收上游更新。

## 决策

保留上游执行引擎、会话、工具审批和目录布局。在媒体脚本的供应商协议边界保留阿里云适配，
用 `ASR_PROVIDER`、`DASHSCOPE_*` 和独立 `IMG_*` 选择服务。当前聊天继续使用 OpenClaw 加阿里云模型，
不因为发现另一个 CLI 就切换到它的原生模型或认证。

API Key、本机配置、账号登录与内容产物不随 Git 同步，不提交到 Fork 或上游。
每个补丁登记在 `docs/patch-register.md`；升级固定到已发布版本的具体提交，在独立分支通过测试与启动验收后再更新 Fork。

## 影响

上游会话和执行引擎改动可以正常合并。少量设置页桥接仍需人工核对，但不维护整份旧设置页。
模型支持、原生协议与账号访问权限分别验证；“已配置”和历史实测结果不代表实时在线。
升级失败可以退回已保存的源码提交和本机配置备份。
